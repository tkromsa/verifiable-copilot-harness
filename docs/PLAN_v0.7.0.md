# VCH v0.7.0 Simplification Plan

Status: DRAFT, not started
Source version: v6.15.1
Target version: v0.7.0 (version renumbering — the harness is not 1.0-grade mature; major version shifts down by design)

## Goals

1. Remove `VCH_ProjectTemplate.xlsx`. Single behavior kernel: `VCH_HarnessCore.xlsx`.
   Delivery sheets (01_Plan .. 09_Worklog) are generated by PROJECT-FORK from an embedded
   `__DELIVERY_SCHEMA` sheet, not shipped as a second workbook.
2. Collapse workbook modes from 5 to 3: HARNESS, PROJECT, MIGRATION.
   TEMPLATE and PROJECT-CREATION disappear.
3. Add a universal NEXT footer: every reply ends with a recommended next action and
   (when applicable) a recommended skill. Source of recommendations is the existing
   deterministic `May_Chain_To` column, mode-filtered via `Allowed_Modes`.
4. Renumber the release line to v0.7.0 and rework the whole GitHub presence
   (README, release, manifest, all 4 wiki pages).

## Non-goals

- No skill count change (43 skills stay; only Allowed_Modes values change).
- No change to sovereign rules (SCRUB, FROZEN ORACLE, EVIDENCE, NO CAPABILITY INHERITANCE,
  CHARACTER POLICY).
- No change to persistence modes (ARTIFACT_COPY_ON_WRITE, PRECOPIED_ARTIFACT,
  EXCEL_NATIVE_VERSIONING, READ_ONLY, WRITE_BLOCKED).
- __ROUTING_ORACLE stays out of the bootstrap read-set.
